# OODS — Brazilian bathing-water samples, raw

The **raw layer** of [marola](https://github.com/h0ffmann/marola)'s open ocean data store: the
files exactly as the monitoring institute served them, byte for byte, BOM and all. Nothing here is
generated by an LLM and nothing is re-derived — a verdict is the agency's own.

The rest of the store — the manifest that indexes these files, the Parquet partitions rebuilt from
them, and the SQL that does the rebuilding — lives in the repository, under `data/oods/` and
`oods/sql/`. Only the raw layer is here, because 3,331 small CSVs are a tree git could carry but no
human could review in a pull request.

## Source

**IMA/SC** — Instituto do Meio Ambiente de Santa Catarina, whose bathing-water programme publishes
a per-beach CSV history back to 2003 at
[balneabilidade.ima.sc.gov.br](https://balneabilidade.ima.sc.gov.br). Two endpoints are used:
`/relatorio/exportarCSV` (one beach-year per request) and `/relatorio/mapa` (the sampling-point
registry with coordinates). Sampling is weekly in season, monthly off season.

## Layout

```
raw/ima-sc/
  points.json                              the /relatorio/mapa registry, sorted by CODIGO
  csv/<municipio>/<beach>/<year>.csv       exportarCSV bytes verbatim — slugs are ASCII
```

`data/oods/manifest/ima-sc.json` in the repository is the index: one entry per file keyed by the
same `raw/...` path, carrying the source URL, sha256, byte count, fetch time and row count. A
file's public URL is `https://huggingface.co/datasets/h0ffmann/oods-br-bathing-water/resolve/main/<key>`.

## Reading it

```sql
SELECT count(*) FROM read_csv(
  'hf://datasets/h0ffmann/oods-br-bathing-water/raw/ima-sc/csv/**/*.csv',
  header = true, all_varchar = true);
```

Five beach-years the portal itself cannot export are absent, not missing: they are listed as
`known_broken` in the repository's `data/oods/sources.json`, with the HTTP failure observed for
each.

it is not on `dados.sc.gov.br`. It is public administrative information under the Lei de Acesso à
Informação (Lei 12.527/2011), which is the basis Brazilian civic-data projects cite — but that is
not a licence grant, so no licence is claimed here for the source data, and no CC badge is shown.
Treat these files as a redistributed copy of IMA's public data, attributed to IMA/SC.
