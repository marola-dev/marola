API — Scala

  • core — pipeline logic, scoring, the pluggable traits
  • local — Ollama-backed implementations, the water-quality parsers
  • cli — Main, AppConfig, the MCP tool server

API — Python

  • scripts — the repo's own tooling
  • finetune — the marola-sea training, merge and publish chain

CLI scripts rather than a library, all stdlib-only at import time — the finetune ones keep torch and peft behind lazy imports so they document (and self-test) without the ML stack. Read it as a tour of the tooling, not a reference.
