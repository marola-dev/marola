Decisions taken for v1 (MIP §11), so that the tasks above are unambiguous:

1. **Tiles:** Leaflet with a raster tile URL template per area (`tiles` in `areas.json`), default
   OpenStreetMap's public tiles with the required attribution, acceptable for the friends-only
   phase only. Switching to Protomaps (self-hosted PMTiles) before any public link stays open and is
   documented in the MIP; nothing in the page depends on the tile source.
2. **Areas:** Florianópolis (`floripa`, radius 30 km) and Rio (`rio`, radius 20 km, no water
   provider there, so the card says "no data"). Two areas prove the multi-area path at the cost of
   two Overpass queries per run.
3. **Hour slider:** yes; every daylight hour is in the board.
4. **LLM summary:** not in the board for v1 (no GPU host builds it); the deterministic notes are the
   "why". Adding an optional `summary` field later is a serializer change only.
5. **Deploy:** GitHub Pages from the scheduled workflow (free, no secret, the repo is already on
   GitHub); Cloudflare Pages documented as the one-line alternative.

Restack notes: task 3 only adds files under `site/static/` that task 2 copies, and task 4 only adds
a workflow, a recipe and docs — no task rewrites a file an earlier task created.
