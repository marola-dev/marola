## Decisions

1. **Order.** After MIP-0044 task 1, which moves `#sound` into the menu, and before MIP-0054 task 2,
   which wraps these same strings in `t()`: the other order means rewriting every call site twice.
   Before MIP-0042's `/v1/` freeze, as §11 already recommends.
2. **The wind barb has a fallback.** If the 390 px screenshot cannot tell calm from breezy, task 1
   ships the band word without a wind mark (§8) and says so in the PR. That is an accepted outcome.
3. **Task 2 implements §5.6's rule option** because it is the only one that passes AA in all five
   bands (the table in §5.6). A veto in the acceptance PR changes this row before it is filed.
4. **The markers are not sprited** (§5.2, §9). Their inline filled path stays tuned for area zoom.
