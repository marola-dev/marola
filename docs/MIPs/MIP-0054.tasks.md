## Decisions

1. **The site's catalog is a JS object in `ui.js`**, not `data/i18n/*.json` fetched at load. No
   request before the first render, no flash of the wrong language, works from `file://`, and no
   Scala in the site's half. Recorded in §5.1.
2. **`pt-BR` is the last fallback**, as §5.5 says. In practice `navigator.languages` decides for
   almost every visitor, and the constant only matters to a browser that exposes no language.
3. **Mixed language between tasks 1 and 3 is accepted.** The chrome turns Portuguese while the
   notes, the water summary's month and the lore stay English (§8). Task 3 closes the notes.
4. **The release blocker is unchanged.** Release 0 still waits for the whole MIP, later tasks
   included; this round does not make the release shippable on its own.
5. **A native-speaker pass gates the release, not task 1's merge** (§11), since the page is English
   only today.
