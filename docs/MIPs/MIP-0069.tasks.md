## Decisions

1. **Task 1 was built before this MIP**, on the local map-UX stack, at the user's request on
   2026-09-29. Its PR waits for this MIP's acceptance and its issue like every other task.
2. **Class names do not change**, except `.about-body` becoming `.prose` in task 2, because a news
   post needs the same rules and the old name says "about".
3. **Budgets are measured with CR stripped**, so a Windows checkout and CI see the same number.
4. **The icon sprite stays inline per page** (MIP-0046 §4.2); the kit page carries its own copy,
   and MIP-0044 task 2's generator emits it where a page uses icons.
