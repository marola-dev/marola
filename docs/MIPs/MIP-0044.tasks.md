## Decisions

1. **§5.5 and §5.6 are not tasks.** §5.6 shipped as marola.dev/docs (#300, #306), and MIP-0064
   rebuilt it as an mkdocs site that also publishes `docs/*.md`, which is what §5.5 asked for.
2. **Task 1 lands after the map-behaviour story**, an issue with no MIP that fixes how the list,
   card and chat sheets behave on a phone (one open at a time, Escape, focus return, no `alert()`).
   The story creates `site/static/ui.js` for its sheet registry and adds it to `site.yml` and
   `stamp_site_version.sh`; task 1 adds the menu to it. The `depends on` column cannot name an issue
   outside a tasks table, so that edge is wired by hand after filing:
   `scripts/issues.sh deps add <task-1 issue> --blocked-by <story issue>`.
3. **Task 2 waits for MIP-0054 task 1**, so the generated `/about/` carries both languages the first
   time. That edge is also wired by hand: in the table it would make the two tasks files
   impossible to file in either order, since MIP-0054 task 1 depends on this task 1.
4. **The interim six items ship in task 1 unchanged.** Changing which sections the nav names is the
   nav-switch task, not a side effect of the menu.
5. **The chat toggle moves into the menu in task 1** unless the maintainer vetoes it in the
   acceptance PR (MIP-0044 §11): it changes MIP-0033 §5.2's floating placement.
