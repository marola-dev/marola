train_lora

QLoRA fine-tune of one preset base model on marola's dataset — Tier 2 in README.md.

STATUS: the tiny preset has been run end to end (see finetune/README.md); every larger preset is written against the documented peft/transformers/trl APIs and NOT RUN here. Treat a first run on a new preset as a debugging session, not a build step.

Usage: pip install -r requirements.txt huggingface-cli login # only the gated base preset needs this python build_dataset.py # or: just finetune-dataset python train_lora.py --preset qwen-7b --epochs 3 # then convert out//adapter with llama.cpp's convert_lora_to_gguf.py and # just finetune-adapter-model preset=qwen-7b

Presets (see PRESETS): tiny (SmolLM2-360M, ungated, Apache-2.0, trains on CPU in minutes — the default), small/base (Llama 3.2 1B/3B; the 3B is gated), qwen-4b/qwen-7b/qwen-14b/ qwen-27b (Apache-2.0 throughout). tiny is the default rather than small so an unqualified run never silently produces a Llama derivative: the Llama 3.2 Community Licence requires such a model's name to begin with "Llama" and to ship the agreement plus a "Built with Llama" notice (see finetune/README.md). Both Llama presets remain available and are fine to use — they just have to be chosen, and their obligations met, on purpose.

Switching base is safe by construction: each preset trains into its own out/<preset>/ directory, and a run refuses to start if the directory it is about to write already holds another base model's work. On CPU pass --no-4bit (bitsandbytes needs CUDA).

 35# Iterate fast on a tiny model, then re-run the same script on the real one: the dataset, the LoRA
 36# config and the GGUF/Ollama steps are identical, only `--preset` changes.
 37#
 38# Every field has exactly one consumer, so a new preset cannot half-exist:
 39#   hf/ollama      the HF id to train from, and the Ollama model an adapter trained on it attaches
 40#                  to — `ollama create` fails loudly on a tag that does not exist, but attaching to
 41#                  the WRONG one of a family loads fine and then answers nonsense, so both the tag
 42#                  and its variant (instruct vs thinking) are part of the identity.
 43#   params_b       preflight's VRAM/RAM/disk estimator, and the batch/accum split below.
 44#   gated          whether a Hugging Face login is needed before the weights download.
 45#   licence        an HF licence *id*, passed through to publish_hf.py --base-license.
 46#   name_prefix    Meta's Community Licence requires a Llama derivative's name to start with
 47#                  "Llama-" (MIP-0025 §5.1(3)); merge_export.py reads this instead of guessing
 48#                  from the id.
 49#   thinking       the base's chat template emits reasoning blocks, which changes what an SFT run
 50#                  teaches and what the Ollama model answers with.
 51#   target_modules which projections LoRA attaches to. peft matches by suffix and silently skips
 52#                  what it does not find, so a model whose attention is not q/k/v/o_proj needs its
 53#                  own list rather than the standard one.

152def preset_for(hf_id: str) -> str | None:
153    """The preset name that owns this HF id, or None for a `--base` outside the table."""
154    for name, p in PRESETS.items():
155        if p["hf"] == hf_id:
156            return name
157    return None

160def ollama_base_for(hf_id: str) -> str:
161    """The `FROM` line Modelfile.adapter needs — the adapter only fits the family it was trained on."""
162    name = preset_for(hf_id)

166def run_slug(hf_id: str) -> str:
167    """The per-run directory name: the preset when there is one, else a slug of the model id.
168
169    Artifacts are namespaced by this rather than shared, because everything downstream of training
170    is model-shaped: an adapter, a merged checkpoint and a GGUF built from SmolLM2 mean nothing to
171    a Qwen run, and `save_total_limit` deletes by step number without looking at whose checkpoint
172    it is — the two bases' step counts differ, so a shared directory loses whichever run wrote
173    fewer steps.
174    """
175    name = preset_for(hf_id)
176    if name:
177        return name
178    return re.sub(r"[^a-z0-9]+", "-", hf_id.rsplit("/", 1)[-1].lower()).strip("-") or "custom"

191def has_artifacts(out: Path) -> bool:
192    """Does this directory already hold a training run's output?"""
193    return bool(list(out.glob("checkpoint-*"))) or (out / "adapter_config.json").exists()

196def base_conflict(marker_text: str | None, base: str) -> bool:
197    """True when a directory's recorded base model is not the one about to be trained."""
198    return bool(marker_text) and marker_text.strip() != base

201def read_marker(out: Path) -> str | None:

206def check_base(out: Path, base: str) -> None:
207    """Refuse to write a second base model's run into another's directory.
208
209    Optimizer, scheduler and adapter shapes are all model-specific: resuming a SmolLM2 checkpoint
210    into a Qwen run either explodes with a shape error or, worse, trains something meaningless.
211    This runs whether or not `--resume` was passed, because an unguarded run does not resume the
212    other base's work — it overwrites it, and `save_total_limit` can delete it mid-run.
213    """
214    if not out.exists():
215        return
216    previous = read_marker(out)
217    if base_conflict(previous, base) and has_artifacts(out):
218        raise SystemExit(
219            f"train_lora: {out} holds a run trained from {previous.strip()!r}, but this run uses "
220            f"{base!r}. Refusing to mix base models in one directory — delete {out}, or pass "
221            "--out for this base (the default is already per-preset)."
222        )

225def adapter_base(adapter: Path) -> str | None:
226    """Which base model an existing LoRA adapter was trained on, per its own adapter_config.json."""
227    cfg = Path(adapter) / "adapter_config.json"
228    if not cfg.exists():
229        return None
230    try:
231        return json.loads(cfg.read_text()).get("base_model_name_or_path")
232    except json.JSONDecodeError:
233        return None

236def check_adapter_base(adapter: Path, base: str) -> None:
237    """Refuse a mismatched adapter *before* the base model loads.
238
239    peft raises on its own eventually, but only after transformers has pulled a full checkpoint
240    into RAM — up to tens of GB for the larger presets. This is one JSON read.
241    """
242    found = adapter_base(adapter)
243    if found and found != base:
244        raise SystemExit(
245            f"the adapter at {adapter} was trained on {found!r}, not {base!r}. A LoRA adapter only "
246            "fits the family it was trained on — point --sft-adapter/--adapter at this base's run "
247            "(finetune/out/<preset>/), or retrain."
248        )

251def latest_checkpoint(out: Path) -> str | None:
252    """The newest `checkpoint-N` under --out, or None to train from scratch.
253
254    Decided from what is on disk rather than from the flag alone: `--resume` on a clean machine
255    must start from scratch, not fail, or the first run of any CI job breaks.
256    """
257    ckpts = sorted(
258        (d for d in out.glob("checkpoint-*") if d.is_dir()),
259        key=lambda d: int(d.name.rsplit("-", 1)[1]),
260    )
261    return str(ckpts[-1]) if ckpts else None

264def mark_base(out: Path, base: str) -> None:
265    out.mkdir(parents=True, exist_ok=True)
266    (out / BASE_MARKER).write_text(base + "\n")

269def self_test() -> int:
270    """Everything above is pure or filesystem-only — no torch, no network, seconds to run."""
271    import tempfile
272
273    fails = 0
274
275    def ok(got, want, label):
276        nonlocal fails
277        if got == want:
278            print(f"  ok   {label}")
279        else:
280            fails += 1
281            print(f"  FAIL {label} — got {got!r}, want {want!r}")
282
283    for name, p in PRESETS.items():
284        ok(sorted(p), sorted(PRESET_FIELDS), f"{name} declares every preset field")
285        ok(
286            p["licence"] in ("apache-2.0", "llama3.2"),
287            True,
288            f"{name}'s licence is an HF id, not prose (publish_hf --base-license takes it)",
289        )
290        ok(
291            p["name_prefix"] == ("Llama-" if "llama" in p["hf"].lower() else ""),
292            True,
293            f"{name}'s name_prefix matches Meta's obligation for its base",
294        )
295
296    ok(preset_for("Qwen/Qwen2.5-7B-Instruct"), "qwen-7b", "a base id resolves back to its preset")
297    ok(preset_for("mistralai/Whatever"), None, "an unknown base id resolves to no preset")
298    ok(ollama_base_for(PRESETS["qwen-27b"]["hf"]), "qwen3.8:27b", "27B's Ollama tag is qwen3.8")
299    ok(run_slug("Qwen/Qwen2.5-7B-Instruct"), "qwen-7b", "the run directory is the preset name")
300    ok(run_slug("acme/Some_Model-v2"), "some-model-v2", "an off-table base still gets a slug")
301    ok(
302        default_out("Qwen/Qwen2.5-7B-Instruct").parts[-2:],
303        ("qwen-7b", "adapter"),
304        "the default --out is namespaced by preset",
305    )
306    ok(
307        default_out(PRESETS["tiny"]["hf"]) != default_out(PRESETS["qwen-7b"]["hf"]),
308        True,
309        "tiny and qwen-7b cannot land in the same directory",
310    )
311
312    ok(base_conflict("a\n", "b"), True, "a different recorded base is a conflict")
313    ok(base_conflict("a\n", "a"), False, "the same base is not a conflict")
314
315    with tempfile.TemporaryDirectory() as tmp:
316        ad = Path(tmp) / "adapter"
317        ad.mkdir()
318        smol, qwen = PRESETS["tiny"]["hf"], PRESETS["qwen-7b"]["hf"]
319        check_adapter_base(ad, qwen)  # no adapter_config.json yet — nothing to contradict
320        (ad / "adapter_config.json").write_text(json.dumps({"base_model_name_or_path": smol}))
321        ok(adapter_base(ad), smol, "an adapter reports the base it was trained on")
322        check_adapter_base(ad, smol)
323        try:
324            check_adapter_base(ad, qwen)
325            ok("no refusal", "SystemExit", "a foreign adapter must be refused before loading")
326        except SystemExit as exc:
327            ok(smol in str(exc), True, "the refusal names the adapter's real base")
328    ok(base_conflict(None, "a"), False, "an unmarked directory is not a conflict")
329
330    with tempfile.TemporaryDirectory() as tmp:
331        out = Path(tmp) / "adapter"
332        smol, qwen = PRESETS["tiny"]["hf"], PRESETS["qwen-7b"]["hf"]
333        check_base(out, smol)  # nothing on disk yet
334        mark_base(out, smol)
335        (out / "checkpoint-40").mkdir()
336        ok(latest_checkpoint(out), str(out / "checkpoint-40"), "the newest checkpoint is found")
337        try:
338            check_base(out, qwen)
339            ok("no refusal", "SystemExit", "switching base in a used directory must be refused")
340        except SystemExit as exc:
341            ok(smol in str(exc) and qwen in str(exc), True, "the refusal names both base models")
342        check_base(out, smol)  # the same base is still fine
343        (out / "checkpoint-40").rmdir()
344        ok(latest_checkpoint(out), None, "an empty directory resumes from scratch")
345
346    print("train_lora self-test:", "ok" if not fails else f"{fails} FAILED")
347    return 1 if fails else 0

457    import torch
458    from datasets import load_dataset
459    from peft import LoraConfig
460    from transformers import AutoModelForCausalLM, AutoTokenizer

463    cuda = torch.cuda.is_available()
464    device = args.device
465    if device == "auto":
466        device = "cuda" if cuda else "cpu"
467    if device in ("cuda", "hybrid") and not cuda:
468        raise SystemExit(
469            f"train_lora: --device {device} needs a working CUDA device; torch.cuda.is_available() "
470            "is False. Check `nvidia-smi` — a present card with a broken driver looks exactly like "
471            "no card at all here. Use --device cpu to run anyway."
472        )
473
474    # TF32 costs nothing on Ampere and later and speeds up every matmul that is not already bf16.
475    if cuda:
476        torch.backends.cuda.matmul.allow_tf32 = True
477        torch.backends.cudnn.allow_tf32 = True
478
479    tok = AutoTokenizer.from_pretrained(args.base)
480    tok.pad_token = tok.pad_token or tok.eos_token

482    model_kwargs: dict = {"torch_dtype": torch.bfloat16 if cuda else torch.float32}
483    use_4bit = not args.no_4bit and device in ("cuda", "hybrid")
484    if use_4bit:
485        from transformers import BitsAndBytesConfig
486
487        model_kwargs["quantization_config"] = BitsAndBytesConfig(
488            load_in_4bit=True,
489            bnb_4bit_quant_type="nf4",
490            bnb_4bit_compute_dtype=torch.bfloat16,
491            # Quantizing the quantization constants too — ~0.4 bits/param less memory for no
492            # measurable quality cost, which is free headroom on a 24 GB card at 27B.
493            bnb_4bit_use_double_quant=True,
494        )
495    if device == "cuda":
496        model_kwargs["device_map"] = "auto"
497    elif device == "hybrid":
498        # Fill the GPU to a ceiling, spill the remainder to CPU RAM. Slower per step than pure GPU
499        # — every offloaded layer crosses PCIe twice — but it is the difference between running and
500        # an OOM when the model does not fit in VRAM alone. This machine has 188 GB of RAM, so the
501        # CPU side is effectively unbounded.
502        ceiling = args.gpu_mem_gb or (torch.cuda.get_device_properties(0).total_memory / 1e9 * 0.90)
503        model_kwargs["device_map"] = "auto"
504        model_kwargs["max_memory"] = {0: f"{ceiling:.0f}GiB", "cpu": "160GiB"}
505        print(f"hybrid: up to {ceiling:.0f} GiB on the GPU, the rest offloaded to CPU RAM")
506
507    # SDPA is the fastest attention available without a flash-attn build, and unlike flash-attn it
508    # needs no extra wheel — worth asking for explicitly rather than taking the eager default.
509    model_kwargs["attn_implementation"] = "sdpa"
510    model = AutoModelForCausalLM.from_pretrained(args.base, **model_kwargs)
511    if use_4bit:
512        from peft import prepare_model_for_kbit_training
513
514        model = prepare_model_for_kbit_training(
515            model, use_gradient_checkpointing=not args.no_grad_checkpointing
516        )
517
518    data = load_dataset(
519        "json", data_files={"train": f"{args.data}/train.jsonl", "eval": f"{args.data}/eval.jsonl"}
520    )
521
522    # peft matches target modules by suffix and skips what it cannot find, so a hybrid attention
523    # stack needs "all-linear" rather than the q/k/v/o list every other preset uses.
524    targets = preset.get("target_modules", ATTENTION_AND_MLP)
525    lora = LoraConfig(
526        r=args.rank,
527        lora_alpha=2 * args.rank,
528        lora_dropout=0.05,
529        bias="none",
530        task_type="CAUSAL_LM",
531        target_modules="all-linear" if targets == "all-linear" else list(targets),
532    )
533    # Effective batch stays ~8 regardless of size; only how it is split changes. Bigger models get
534    # a smaller per-device batch and more accumulation, because activation memory scales with both
535    # batch and model width.
536    params_b = preset.get("params_b", 1.0)
537    if args.batch is not None:
538        batch = args.batch
539    elif device == "cpu":
540        batch = 1
541    else:
542        batch = 4 if params_b <= 2 else 2 if params_b <= 9 else 1
543    accum = args.grad_accum if args.grad_accum is not None else max(1, 8 // batch)
544
545    cfg = SFTConfig(
546        output_dir=args.out,
547        num_train_epochs=args.epochs,
548        learning_rate=args.lr,
549        per_device_train_batch_size=batch,
550        gradient_accumulation_steps=accum,
551        logging_steps=5,
552        eval_strategy="epoch",
553        save_strategy="epoch",
554        save_total_limit=1,  # a 27B checkpoint per epoch is ~100 GB of churn nobody reads
555        max_length=args.max_len,
556        bf16=cuda,
557        # marola's corpus is ~2.8k mostly-short rows against a 2048-token window, so without
558        # packing most of every batch is padding. Packing concatenates examples up to max_length
559        # and is the single biggest throughput win available here.
560        packing=not args.no_packing,
561        gradient_checkpointing=not args.no_grad_checkpointing,
562        gradient_checkpointing_kwargs={"use_reentrant": False},
563        # Fused optimizer when CUDA is present: fewer kernel launches per step, no accuracy cost.
564        optim="adamw_torch_fused" if cuda else "adamw_torch",
565        # Only useful when packing is off: it batches similar-length examples so a batch is
566        # mostly content rather than padding. With packing on it is redundant.
567        group_by_length=args.no_packing,
568        dataloader_num_workers=4,
569        report_to=[],
570    )
571    print(
572        f"device={device} batch={batch} accum={accum} (effective {batch * accum}) "
573        f"packing={not args.no_packing} grad_checkpointing={not args.no_grad_checkpointing} "
574        f"4bit={use_4bit}"
575    )
576    resume = latest_checkpoint(out) if args.resume else None
577    print(f"resuming from {resume}" if resume else "training from scratch (no checkpoint found)")
578    mark_base(out, args.base)
579    trainer = SFTTrainer(
580        model=model,
581        processing_class=tok,
582        peft_config=lora,
583        args=cfg,
584        train_dataset=data["train"],
585        eval_dataset=data["eval"],
586    )
587    trainer.train(resume_from_checkpoint=resume)
588    trainer.save_model(args.out)
589    print(
590        f"adapter saved to {args.out} — convert with llama.cpp convert_lora_to_gguf.py, then see Modelfile.adapter"
591    )

207def check_base(out: Path, base: str) -> None:
208    """Refuse to write a second base model's run into another's directory.
209

211    into a Qwen run either explodes with a shape error or, worse, trains something meaningless.

484    use_4bit = not args.no_4bit and device in ("cuda", "hybrid")
485    if use_4bit:
486        from transformers import BitsAndBytesConfig
487
488        model_kwargs["quantization_config"] = BitsAndBytesConfig(
489            load_in_4bit=True,
490            bnb_4bit_quant_type="nf4",
491            bnb_4bit_compute_dtype=torch.bfloat16,
492            # Quantizing the quantization constants too — ~0.4 bits/param less memory for no
493            # measurable quality cost, which is free headroom on a 24 GB card at 27B.
494            bnb_4bit_use_double_quant=True,
495        )
496    if device == "cuda":
497        model_kwargs["device_map"] = "auto"
498    elif device == "hybrid":
499        # Fill the GPU to a ceiling, spill the remainder to CPU RAM. Slower per step than pure GPU
500        # — every offloaded layer crosses PCIe twice — but it is the difference between running and
501        # an OOM when the model does not fit in VRAM alone. This machine has 188 GB of RAM, so the
502        # CPU side is effectively unbounded.
503        ceiling = args.gpu_mem_gb or (torch.cuda.get_device_properties(0).total_memory / 1e9 * 0.90)
504        model_kwargs["device_map"] = "auto"
505        model_kwargs["max_memory"] = {0: f"{ceiling:.0f}GiB", "cpu": "160GiB"}
506        print(f"hybrid: up to {ceiling:.0f} GiB on the GPU, the rest offloaded to CPU RAM")
507
508    # SDPA is the fastest attention available without a flash-attn build, and unlike flash-attn it
509    # needs no extra wheel — worth asking for explicitly rather than taking the eager default.
510    model_kwargs["attn_implementation"] = "sdpa"
511    model = AutoModelForCausalLM.from_pretrained(args.base, **model_kwargs)
512    if use_4bit:
513        from peft import prepare_model_for_kbit_training
514
515        model = prepare_model_for_kbit_training(
516            model, use_gradient_checkpointing=not args.no_grad_checkpointing
517        )
518
519    data = load_dataset(
520        "json", data_files={"train": f"{args.data}/train.jsonl", "eval": f"{args.data}/eval.jsonl"}
521    )
522
523    # peft matches target modules by suffix and skips what it cannot find, so a hybrid attention
524    # stack needs "all-linear" rather than the q/k/v/o list every other preset uses.
525    targets = preset.get("target_modules", ATTENTION_AND_MLP)
526    lora = LoraConfig(
527        r=args.rank,
528        lora_alpha=2 * args.rank,
529        lora_dropout=0.05,
530        bias="none",
531        task_type="CAUSAL_LM",
532        target_modules="all-linear" if targets == "all-linear" else list(targets),
533    )
534    # Effective batch stays ~8 regardless of size; only how it is split changes. Bigger models get
535    # a smaller per-device batch and more accumulation, because activation memory scales with both
536    # batch and model width.
537    params_b = preset.get("params_b", 1.0)
538    if args.batch is not None:
539        batch = args.batch
540    elif device == "cpu":
541        batch = 1
542    else:
543        batch = 4 if params_b <= 2 else 2 if params_b <= 9 else 1
544    accum = args.grad_accum if args.grad_accum is not None else max(1, 8 // batch)
545
546    cfg = SFTConfig(
547        output_dir=args.out,
548        num_train_epochs=args.epochs,
549        learning_rate=args.lr,
550        per_device_train_batch_size=batch,
551        gradient_accumulation_steps=accum,
552        logging_steps=5,
553        eval_strategy="epoch",
554        save_strategy="epoch",
555        save_total_limit=1,  # a 27B checkpoint per epoch is ~100 GB of churn nobody reads
556        max_length=args.max_len,
557        bf16=cuda,
558        # marola's corpus is ~2.8k mostly-short rows against a 2048-token window, so without
559        # packing most of every batch is padding. Packing concatenates examples up to max_length
560        # and is the single biggest throughput win available here.
561        packing=not args.no_packing,
562        gradient_checkpointing=not args.no_grad_checkpointing,
563        gradient_checkpointing_kwargs={"use_reentrant": False},
564        # Fused optimizer when CUDA is present: fewer kernel launches per step, no accuracy cost.
565        optim="adamw_torch_fused" if cuda else "adamw_torch",
566        # Only useful when packing is off: it batches similar-length examples so a batch is
567        # mostly content rather than padding. With packing on it is redundant.
568        group_by_length=args.no_packing,
569        dataloader_num_workers=4,
570        report_to=[],
571    )
572    print(
573        f"device={device} batch={batch} accum={accum} (effective {batch * accum}) "
574        f"packing={not args.no_packing} grad_checkpointing={not args.no_grad_checkpointing} "
575        f"4bit={use_4bit}"
576    )
577    resume = latest_checkpoint(out) if args.resume else None
578    print(f"resuming from {resume}" if resume else "training from scratch (no checkpoint found)")
579    mark_base(out, args.base)
580    trainer = SFTTrainer(
581        model=model,
582        processing_class=tok,
583        peft_config=lora,
584        args=cfg,
585        train_dataset=data["train"],
586        eval_dataset=data["eval"],
587    )
588    trainer.train(resume_from_checkpoint=resume)
589    trainer.save_model(args.out)
590    print(
591        f"adapter saved to {args.out} — convert with llama.cpp convert_lora_to_gguf.py, then see Modelfile.adapter"
592    )
